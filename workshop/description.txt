エンシェント・ボス・アセンションを自由に設定できるMODです！

[h2]主な機能[/h2]
[list]
[*][b]エンシェント・ボス選択[/b]：各Actに登場するエンシェントとボスを選べます。
[*][b]アセンション個別設定[/b]：各効果を個別にON/OFFできます。例：A1はOFF、A2だけON。
[/list]
※マルチプレイにも対応するよう実装していますが、実際の動作確認はまだです。週末にフレンドとテスト予定です。

[hr][/hr]
A mod that lets you freely customize Ancients, bosses, and Ascension effects!

[h2]Features[/h2]
[list]
[*][b]Ancient & Boss Selection[/b]: Choose which Ancients and bosses appear in each Act.
[*][b]Individual Ascension Settings[/b]: Enable or disable each effect independently. For example, turn A1 OFF while keeping A2 ON.
[/list]
Multiplayer support has been implemented but hasn't been tested yet. I'm planning to test it with friends this weekend.
